사고접수 Assistant 사용설명서

이 문서는 모형(mock) 프로젝트의 설명서입니다. 여기 나오는 시스템명·화면명·데이터는 모두 일반화한 가상의 값이며, 연동 대상은 로컬 모의 서버(localhost:8081~8086)입니다. 실제 연동 대상은 공개 저장소에 포함되어 있지 않습니다. 스크린샷의 고객정보·식별정보는 마스킹·블러 처리했습니다.

사고관리 시스템·차량관리 시스템·고객문의 시스템·사후관리 기록 시트, 네 시스템을 오가던 작업을 한 줄기로 모아 포털 페이지 좌측에 고정된 사이드바 하나에 담아 둡니다.

설치

설치 가이드

chrome://extensions · 압축해제된 확장 프로그램 로드

이 확장 프로그램은 Chrome 웹스토어가 아니라 압축해제된 상태로 배포됩니다. 배포 폴더를 내려받은 뒤 chrome://extensions 페이지에서 아래 3단계로 한 번만 로드하면, 이후에는 대상 포털 페이지를 열 때마다 사이드바가 자동으로 나타납니다.

screenshots/install-01-dev-mode.png

1. 배포 폴더에서 최신 버전 zip 파일의 더보기(⋮) 메뉴 → "다운로드"를 클릭합니다.

screenshots/install-02-load-unpacked.png

2. chrome://extensions에서 ① "개발자 모드"를 켜고 ② "압축해제된 확장 프로그램을 로드"로 압축 해제한 폴더를 선택합니다.

screenshots/install-03-installed.png

3. 목록에서 토글이 켜진 상태로 확장이 뜨면 설치 완료입니다.

⚠

설치 후 사이드바 하단의 설정 패널에서 개인 설정을 완료한 뒤 사용하세요.

V

고객문의 시스템

고객문의 시스템 · panel-inquiry

고객센터(고객문의 시스템) 인입 콜백을 실시간으로 보여주는 패널입니다. 사고접수 흐름의 시작점 역할을 합니다 — 콜백이 뜨면 소리/LED로 알려주고, 고객의 예약·사고이력 정보를 바로 옆에서 확인한 뒤 사고관리 시스템 패널로 넘어갈 수 있습니다.

screenshots/inquiry-01-panel-overview.png

고객문의 시스템 패널 전체 개요, 콜백 대기 카드가 상단에 보이는 상태

1

콜백 대기 알림

콜백 대기 시 LED·카드가 붉게 강조되며 알림음이 울립니다. 기존 알림을 대체하므로 설치된 콜백 알림은 지워주세요.

2

예번 클릭 → 고객·차량정보 자동 전달

고객문의 시스템 화면에서 사고접수가 필요한 예약번호(예번)를 클릭하면, 고객·차량정보가 포털 페이지로 자동 전달됩니다.

3

예약 정보 · 사고이력

예약번호/차량번호 칩 클릭 시 차량관리 시스템 상세로 이동. 사고이력은 날짜 필터로 좁혀볼 수 있습니다.

사

사고관리 시스템

사고관리 시스템 · panel-accident (패널 상단 타이틀: 사고카드)

사고관리 시스템 전산의 사고카드와 연결된 상태에서 SMS 발송·이력 등록, 사고카드 자동 생성, 인근 공업사 확인(긴급출동)까지 처리하는 패널입니다. 이 패널이 열려 있을 때 사고카드 화면과 실시간으로 연동됩니다.

screenshots/accident-06-emergency-list.png

사고카드가 연결된 상태 화면

1

연결 상태 확인

상단 점이 초록색이면 정상 연결 상태입니다. 인증 타이머가 촉박하면 "연장" 버튼으로 연결 시간을 늘립니다.

2

SMS 수신 대상 선택

자동으로 불러온 수신자 중 고르거나, "직접입력"으로 수신받을 전화번호를 입력할 수 있습니다.

3

문자발송 / 이력 생성

문자양식을 체크하고 "발송하기"로 고객에게 문자를 보냅니다. "이력 남기기"로 사고카드에 바로 이력이 남습니다.

4

사고카드 생성

예약번호 또는 차량번호로 새 사고카드를 자동 생성합니다. 포털 페이지 사고접수 양식을 먼저 완성해두면 생성이 원활합니다.

5

긴급출동 — 인근 공업사 확인

현재 차량의 위치 기준으로 가까운 공업사를 거리순으로 찾아줍니다.

6

공업사 선택 → 입고지 자동 기재

공업사 카드 클릭 시 입고지 항목이 자동 채워집니다. 야간입고 배지로 안내문구를 복사할 수 있습니다.

⚠

포털 페이지 내 사고접수 예번/차번과 생성한 사고카드의 예번/차번이 일치해야 사고카드가 연결됩니다.

옥

차량관리 시스템

차량관리 시스템 · panel-vehicle

이 확장 프로그램에서 가장 기능이 많은 패널입니다. 차량관리 시스템(차량관리 시스템 · 모의 서버)의 대차/CS블락, 탁송 블락, 수기대차 처리를 한 곳에서 다룹니다. 상단에 3개의 큰 탭 (차량관리 · 탁송 · 수기대차)이 있고, "수기대차" 탭 안에는 다시 3개의 하위탭(대차차량검색 · 수기대차블락 · 고객예약변경)이 있어 실질적으로 5개의 작업 화면으로 구성됩니다.

3개 상위 탭 전환

패널 상단의 탭바로 차량관리 / 탁송 / 수기대차 화면을 전환합니다. 현재 선택된 탭은 밑줄로 강조됩니다.

탭 1 · 차량관리

차량관리 — 대차/CS블락 추적

현재 진행 중인 대차와 CS블락 현황을 자동으로 스캔해 목록으로 보여줍니다. 구분별(대차/CS블락) 또는 시간순으로 정렬을 바꿔볼 수 있고, 각 카드에서 바로 연장·메모·취소가 가능합니다.

screenshots/vehicle-tracking-03-list-view.png

"예약확인" · "CS블락 생성" 버튼 위치

1

예약확인 / 블락생성 / 새로고침

"예약확인" 버튼으로 고객예약건, 차량 기준 검색결과, 고객 현위치 3개의 창을 띄웁니다. "CS블락 생성" 버튼을 통해 cs블락 3일을 바로 생성합니다. 필요 시 상태 새로고침과 초기화를 해주세요.

2

정렬 기준 전환

"구분별"은 대차/CS블락을 그룹으로, "시간순"은 대여시각 기준 하나의 목록으로 보여줍니다. 미래건이 될수록 최상단에 위치합니다.

3

대차 카드

"자동"은 자동대차 화면을, "예약"은 예약 상세 창으로 연결됩니다.

4

CS블락 카드

내가 생성한 블락엔 "연장" 버튼으로 시간을 바로 조정하고, "메모"·"취소"로 관리합니다.

5

CS블락 생성

상단 "CS블락 생성" 버튼으로 사고 CS블락을 만듭니다. 플랜 예약건은 버튼이 비활성화됩니다.

탭 2 · 탁송

탁송 블락 자동 생성기

배송 필요한 예약번호만 입력하면, 선택한 정위치블락/배송블락에 대한 탁송 블락을 만들어주는 화면입니다.

screenshots/vehicle-transport-02-visualizer.png

검색창 · 블락 선택 화면

1

대차 예약번호 검색

검색창에 탁송이 필요한 대차 예약번호를 입력하고 Enter를 누르면 해당 대차 건의 차량명을 보여줍니다.

2

블락 시각화에서 선택

위/아래 정위치블락·배송블락 버튼을 클릭해 선택 상태(파란색)로 바꿉니다.

3

상세정보 툴팁 확인

대차 예약건에 마우스를 올리면 예약번호·차량·회원·기간·출발지 툴팁이 나타납니다.

4

탁송 블락 생성

블락을 하나 이상 선택하면 "탁송 블락 생성" 버튼이 활성화됩니다. 이후 "대차 필요한 고객"의 예약번호를 반드시 입력해주세요.

탭 3 · 수기대차

수기대차 — 3개 하위탭

자동화가 어려운 경우 수기로 대차/블락/예약을 처리하는 탭입니다. 하위탭 3개(대차차량검색 · 수기대차블락 · 고객예약변경)가 있습니다.

하위탭 1 · 대차차량검색

전국 대차차량 탐색

대차가 필요한 예약을 기준으로 전국의 대차 가능 차량을 지도에서 검색합니다. 차량 확보가 필요한 예번 을 반드시 입력해주세요.

screenshots/vehicle-carsearch-03-map.png

지도 위 핀/거리 표시 결과

1

예약번호 조회

대차 필요한 예약번호를 입력하고 조회합니다.

2

차급 필터 선택(선택사항)

차종 자동판별이 안 맞으면 승용/SUV/기타 칩에서 직접 고를 수 있습니다.

3

지도에서 후보 위치 확인

검색이 완료되면 후보 차량들이 지도 위에 거리와 함께 표시됩니다.

4

탐색 결과 목록에서 선택

지도 아래 결과 목록에서 확인하고, 부족하면 "계속 탐색"으로 범위를 넓힙니다.

하위탭 2 · 수기대차블락

대차 차량 블락 점유

예약번호와 차량번호를 순서대로 조회한 뒤 CS블락을 수기로 생성하는 3단계 화면입니다.

screenshots/vehicle-manualblock-01-search.png

수기대차블락 입력화면

1

대차 필요한 예약번호 조회

대차가 필요한 고객의 예약번호를 먼저 입력해주세요.

2

대차할 차량번호 입력

확보한 대차차량의 차량번호를 입력해주세요.

3

차량번호 조회 → CS블락 생성

버튼을 눌러 수기대차블락을 생성하세요. 이후 생성된 블락 예번을 알려드립니다.

하위탭 3 · 고객예약변경

점유 차량 고객 예약으로 등록

수기로 점유해둔 대차블락을 실제 고객 예약으로 전환하는 3단계 화면입니다.

1

기존 고객 예약번호 조회

대차가 필요했던 기존 고객 예약번호를 입력해 조회합니다.

2

점유한 대차블락 예약번호 조회

수기대차블락 탭에서 만들어둔 블락의 예약번호를 입력해 조회합니다.

3

실행 — 진행 상태 확인

"수기대차" 버튼을 누르면 대차블락 취소 → 고객 예약 취소 → 신규 예약창 열기 3단계가 순서대로 진행되며, 각 단계의 성공/실패가 표시됩니다.

4

신규 예약 유형 선택

신규 예약창을 열기 직전, 왕복 또는 부름 중 어떤 방식으로 열지 묻는 모달이 뜹니다.

⚠

실행하면 기존 고객 예약건이 자동 취소됩니다. 먼저 대차블락을 확보해 둔 뒤 고객과 통화 중(또는 이후)에 진행하세요.

GS

사후관리

사후관리 · panel-post

사진 업로드 여부를 이제 사고관리 시스템 페이지에서 매번 들어가 확인할 필요 없습니다. 자기 시트로 연결하면, 검수 필요한 목록을 자동으로 확인해 각 사고접수건에 사진이 등록되어있는지 확인 후 시트에 기재해줍니다.

1

연동 시트 안내

패널 상단에 현재 참조 중인 시트 이름 설정 위치(설정 탭)에 대한 안내 문구가 표시됩니다.

2

지금 바로 검수 스캔

버튼을 눌러 사진 검수가 필요한 목록을 시트에서 확인합니다.

3

진행 단계 확인

대기건 탐색 → 사진 검수 → 검수 완료 3단계가 순서대로 채워지며 진행 됩니다.

4

마지막 동기화 시각

패널 하단에서 가장 최근에 스캔이 실행된 시각을 확인할 수 있습니다.

⚠

설정 탭에서 자신의 사후관리 시트명을 먼저 입력해야 이 패널이 동작합니다.

공

공지사항

공지사항 · panel-notices

관리자가 기록 시트로 작성한 공지를 사이드바 안에서 바로 확인합니다. 긴급 공지는 안 읽었을 때 목록 맨 위에 고정되고, 상담사가 직접 원하는 공지를 고정해둘 수도 있습니다. 새 버전이 배포되면 패널 상단에 업데이트 배너가 함께 뜹니다.

screenshots/notices-02-list-tabs.png

정렬기준에 따른 공지화면

1

안읽음 배지

공지사항 아이콘에 안 읽은 개수가 빨간 배지로 표시됩니다. 상세 공지 화면 하단의 "확인함으로 표시"로 읽음 처리합니다.

2

상세 공지 화면

패널(하단): 설정 · panel-settings

기록 시트 연동 정보와 고객문의 알림음을 설정하는 패널입니다. 두 그룹 모두 기본은 접힘 상태이며, 클릭해서 펼친 뒤 값을 입력하고 우측 상단 "저장" 버튼으로 반영합니다.

1

기록 시트 연동 정보 입력

2

고객문의 시스템 알림 설정

저장
